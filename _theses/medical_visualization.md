This thesis aims to develop a set of Python tools for the visualization and
interactive exploration of medical volumetric data and 3D shape
reconstructions. The project will leverage both MRI volumes and their
corresponding 3D segmented shapes to build flexible and user-friendly packages
for data inspection, rendering, and interactive exploration. The focus will be
on creating integrated visualization pipelines that allow users to combine
volumetric views with surface meshes and manipulate rendering parameters.
Additionally, the project will include Python scripts and modules to interface
with Blender, enabling high-quality 3D visualizations, animations, and
automated rendering of anatomical structures. The objective is to provide a
comprehensive toolkit for researchers in medical imaging.

#### Data
The dataset consists of real 3D MRI volumes of different anatomical structures.
Each volume includes segmentation labels for anatomical structure, which will
be used to generate visualizations.

#### Expected Outcomes

- Python visualization modules capable of rendering MRI volumes, segmented structures, and 3D surfaces.

- Integrated visualization pipelines combining volumetric and surface representations, with interactive exploration features.

- Python scripts for Blender integration to automate import and rendering 3D shapes.
